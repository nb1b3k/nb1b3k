  ### Featured project

  #### [SecureFlow AI](https://github.com/nb1b3k/secureflow-ai)

  Agentic DevSecOps pull-request security reviewer. Combines 5 deterministic scanners (Gitleaks, Semgrep, Grype, Checkov, AI Discovery) with 4 LLM reasoning
   agents (AI Discovery, Exploitability, STRIDE Threat-Model Delta, Patch Generation + Review). 40-fixture evaluation harness with 80/80 clean orchestrator
  runs on Ubuntu CI. AGPL-3.0.

  `Python` &nbsp;·&nbsp; `LangGraph` &nbsp;·&nbsp; `Pydantic` &nbsp;·&nbsp; `GitHub Actions` &nbsp;·&nbsp; `LLM` &nbsp;·&nbsp; `STRIDE`
